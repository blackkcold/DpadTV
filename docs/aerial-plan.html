风险

  • MiTV 跑不动模糊 → 全程不做 RenderEffect，渐变 scrim 代替；P2 写实测帧率
  • hero 缺 backdrop 图 → 用 cover 放大压暗，不阻塞
  • 3 米对比度 → MUTED 提到 62% 白（现在是灰蓝 #94A3B8）
  • 玻璃叠层糊掉 → 最多两层，hero 固定压 55%
  • 现有截图过期 → 按阶段追加，不一次性重写文档

验收

  • 任意屏字号不超过 4 种；强调色全屏不超过 3 处
  • 焦点在暗海报 / 亮海报上都清晰可见
  • 首页一屏 ≥2.5 行，左右不再有"半张海报"
  • 电视实机 1080p 与模拟器逐屏一致；播放器控制条出现/消失不跳版
