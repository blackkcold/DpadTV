04

机制

点击切换
  • 三分法：surfaces（跟随主题）/ onImage（恒定：幕布、压图的字、播放器控制条、焦点 halo、二维码）/ status（语义色两套明度）。
  • 旧名字保留：Theme.INK 等 109 处一行没改，只把 val 换成 get()；SURFACE/PANEL 直接映射到 glass1/glass2。
  • 工厂：glass() scrimTop/Bottom() edgeFade() focusRing()，新代码不许再写十六进制。
  • 入口唯一：syncTheme()；触发点 = 设置页选模式 / 时间到点 / 时间·时区变更广播 / onResume。
  • 就地重画：换肤入口只在设置页，所以重画目标恒为 showSetup()，焦点回到「外观」。
  • 三个不换肤时刻：播放器在前台（pending 到 onResume）、有弹窗打开、正在输入 —— 看片中途整屏变白是唯一的事故形态。
  • 别的页面到点翻转：靠缓存入参重放 detail / results / browse，不丢正在看的片子。
  • 默认 07:00–19:00 浅色，其余深色；start == end 视为非法 → 恒深色。
  • 排程：Handler.postDelayed 到下一个边界 + 1s；时间/时区变更由动态广播纠正；onResume 再补一次（后台放几天也能纠回来）。
  • 用 Calendar 不用 java.time：minSdk 23 且没开 desugaring，java.time 会在老设备上崩。
  • 不做日出日落：要定位权限，电视上没有合理授权入口；固定窗口覆盖 95% 场景。
  • 弹窗统计别只 grep 你记得的文件：PosterActions.kt 只有 61 行、一行 Builder(host)，第一次验收就是它漏成深底。
  • 浅色对话框的 parent 必须是 Theme.Material.Light.Dialog.Alert，否则单选列表会「深底深字」。
  • halo 40% 不够：中灰海报上只有 2.64:1，加到 60% 黑 / 92% 白才 3.2 / 3.6。
  • 页面底色必须走 Theme.BG：ShelvesScreen 里一行 parseColor("#0b1220") 就让整个首页停在旧配色上（截图当场抓到）。
05

边界

不做的事
项处置理由
首帧窗口底统一深色windowBackground 由系统选，app 内模式它不知道；浅色下闪一帧深色比白闪柔和，彻底解决要自定义 Splash。
系统输入法跟随系统键盘是系统的，深色主题下调出浅色键盘会突兀，无解。
播放器控制条不跟随对比度基准是视频画面；浅色白玻璃在亮场景里会消失。
二维码永远深码浅底反色码在中低端手机扫码器上识别失败，不是审美问题。
Aerial 逐屏改造本轮不动hero 幕布、edgeFade、三级字号只是备好了工厂，逐屏仍按 AERIAL-PLAN.md 的 P1/P2 走。
完整方案与验收：docs/THEME-PLAN.md 电视只安装 · 未做实机测试 · 旧 pro 已卸载并回填 prefs
