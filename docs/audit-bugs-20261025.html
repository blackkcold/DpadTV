影响 年份 chip 永远 0 命中；movie_2025 / tv_* 等 4 个货架每次启动都回落联网（2.5s 节流起，还可能吃 60 分钟风控）——「本地优先 0 请求」的前提被打掉一半。

#问题为什么怎么修
1联网兜底后永远只有第一页
CollectionRepo.kt:104-106
`if (local.size >= 6 || (q.start > 0 && local.isEmpty() && index.available))` → 联网给了 20 条后，loadMore 的 start=20 本地必空、直接返回空并 `done=true`。本地空且已判定要联网时，照旧打网络 start=q.start；本地只有「整页填满」才算命中。
2切换筛选无请求令牌
BrowseScreen.kt:330 / 303 / 362
三处都是 `scope.launch { … items.clear(); addAll(page) }`，先发的慢响应回来会覆盖后发的结果并改写 status。加自增 reqId 或持有 Job cancel 前一个，回来先比 token；launch 外层 try/finally 复位 loading 与进度条。
3「按 OK 重试」不可聚焦
BrowseScreen.kt:88 / 346
status 是 TextView，无 isFocusable；`status.setOnClickListener { reload() }` 在电视上永远按不到。失败态换成可聚焦按钮（或给 status 设 focusable + 焦点环）。
4筛选器焦点归还靠 tag，"全部" 三行重名 → 焦点跳回年份行
BrowseScreen.kt:257 / 231
`tag = v`，`findViewWithTag<View>(v)?.requestFocus()`；年份/地区/类型都有「全部」。tag 带维度前缀 `"$name:$v"`，或记录（行,列）索引后按索引 requestFocus。
5loadRef 仍是「清空 + 加载中」白屏，且文案还在说侧车
BrowseScreen.kt:297-315
`items.clear(); adapter.notifyDataSetChanged(); status.text = "加载中"`；OF astate 文案「缓存还没准备好，等侧车预热」——sidecar 已删。与 reload() 统一：不清空、走 3dp 进度条、失败可重试；把侧车文案换成索引口径。
6ttlMs 形参没接线，所有「重试/强刷」都是假的
CollectionRepo.kt:67 / 102 / 142
`fetch(ref, ttlMs)`、`fetchQuery(q, ttlMs)` 都收了参数，但 `cached(key, block)` 没有 ttlMs，恒用 7 天 TTL。ttlMs 透传到 cached/readCache；ttlMs==0 跳过读缓存，成功后覆盖。
7「快进/快退步长」设置不生效
PlayerActivity.kt:742-749
播放器硬编码 `seekBy(if (event.repeatCount > 0) 15_000L else 10_000L)`；Prefs.seekStepSeconds 只在设置页被读写。seekBy(prefs.seekStepSeconds * 1000L)，长按 ×1.5。
8本地索引把四种 ref 抹平成同一批，首页电影行 = 评分榜
CollectionRepo.kt:70-71（fetch 本地分支）
本地命中不看 ref.kind/sort：HOT / TOP250 / 9分+ / 新片都变成「电影按评分前 60」，去重后整行归最高权重榜，dominant 角标一抑制就一个角标都不剩。本地按 ref.kind/sort 分派（HOT 用扰动、LATEST 用年份、DOULIST 走白名单）；补位循环同样校验 40% 配额。
9CollectionRepo 每进一屏新建一次
MainActivity.kt:3187 / 3215
`CollectionRepo(this)` 在 ShelvesScreen 与 openShelf 各建一个 → 45KB gzip 索引重复解析、Mutex 节流与 60 分钟 blockedUntil 只活在一个实例里，返回再进立刻又能打一轮豆瓣。提到 Application 级单例（含 LocalIndex）。
10返回栈丢来源：从筛选页/片单进详情，返回一律回首页

`"browse", "library" -> showShelves()`；`showRecommend()` 首行又 `if (prefs.shelvesEnabled()){ showShelves(); return }`。detail 记住 origin（results/browse/library/history）并回原样重建，筛选与滚动位置一起恢复。
11「查看更多」带入的 initial 与页面 base 不是同一个查询
BrowseScreen.kt:147-153 / MainActivity.kt:3218
4 个榜合并（含 7.x 分）塞进 base=电影+9分+ 的页面，页头却写 9 分+；续页从 start=18 接，9 分+ 真正前 18 条永不出现。initial 的 Query 与 defaultQuery 不一致就置空走 reload；或记录 Query 后按 (query, offset) 对齐。
