这一版最大的坑：豆瓣限流

HTTP 200，但内容是拒绝
{"msg":"检测到有异常请求从您的IP发出，请登录再试!","r":1}
今天被触发 3 次，全是并发请求导致。定下的六条纪律：
① 全局 Mutex 串行，同一时刻只有一个请求在飞　② 间隔 ≥ 2.5s（650ms / 1.5s 都在 4–6 个请求后就被封）
③ 首页单条流水线：一行拉完再拉下一行　④ 命中即 退避 10 分钟，期间只读缓存，UI 明确提示
⑤ 失败回退过期缓存（宁旧不空）　⑥ 缓存键分离：首页 ref.id、筛选 q_md5(url)，各 24h
