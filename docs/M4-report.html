01

推荐怎么算

纯本地、纯函数、可单测
层做法为什么这么定
信号片单四态 + 播放次数（ev 表），收藏 1.0 / 在看 0.9 / 看过 0.8 / 想看 0.5 / 弃剧 −0.6，30 天半衰不猜类型标签——一猜就得再打豆瓣，而豆瓣是最脆的一环
特征只用「来自哪个榜 + 评分 + 年份」，这些本地一定有零额外请求，断网也能算
打分来源亲和 0.45 / 评分 0.30 / 新鲜 0.15 / 基础 0.10避免变成"再来一屏 9 分老片"
重排MMR（λ=0.35）：同年同评分档相似度 1.0，会被压下去多样性是推荐的底线，不是加分项
门槛信号 < 8 整行不出现一行平庸的推荐比没有更伤
