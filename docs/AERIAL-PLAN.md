# Aerial 一致化方案

> 状态：**视觉方向仍在，主题基础设施已先行落地** —— 深色 / 浅色 / 按时间三模式、令牌三分法、双环焦点见 `THEME-PLAN.md`。本文只管视觉方向与逐屏改造，令牌细节以那份为准。
>
> 目标：把 DpadTV Pro 从"深蓝底 + 面板卡片"的常规 TV 客户端，收敛成 Apple TV Aerial / tvOS 那种**影像优先、玻璃层、极少 chrome**的观感。设计语言变了，但不是重做功能。

---

## 1. Aerial 拆成五条可执行的规则

| 规则 | 含义 | 反面（我们现在） |
|---|---|---|
| ① 影像是主体 | 屏上最大面积永远是内容图，不是容器 | 深蓝背景 + 实心面板抢视线 |
| ② 层级靠光，不靠色 | 玻璃（白 6%/10% + hairline 12%）叠出层次 | 用 `SURFACE #111827` / `PANEL #1F2937` 三块实色分区 |
| ③ 只留一个强调色 | 强调色只给"焦点环"和"唯一主操作" | 青色按钮铺满导航，蓝/绿/黄/红四色角标 |
| ④ 字号收敛到 3 级 | 40 / 20 / 13，其余都是这三种的变体 | 26/22/18/16/15/12.5/10.5 七级并存 |
| ⑤ 动效短、位移小 | 160ms ease-out，缩放 ≤1.05，不弹跳 | 各自为政的 200~300ms |

**取舍**：玻璃层最多两层（hero 之上的 shelf 容器 + 聚焦卡片），第三层就退化成毛玻璃糊。MiTV 上不做实时模糊（`RenderEffect` 需 API 31 且中低端芯片掉帧），用**预渲染渐变 scrim** 模拟——观感差 10%，性能差 10 倍。

## 2. 令牌 v2（对 `Theme.kt` 的增量）

```kotlin
object Theme {
    // 底色：去掉蓝调，让海报成为屏上唯一的颜色来源
    val BG        = 0xFF07090C
    val BG_DEEP   = 0xFF030406      // hero 幕布底
    // 玻璃：靠 alpha 叠层，不再用实色面板
    val GLASS_1   = 0x0FFFFFFF      // 6%  行容器 / 次级块
    val GLASS_2   = 0x1AFFFFFF      // 10% 聚焦卡片 / 弹层
    val HAIRLINE  = 0x1FFFFFFF      // 12% 1dp 描边
    // 文字
    val INK       = 0xFFF5F7FA
    val MUTED     = 0x9FF5F7FA      // 62% 白
    // 强调：只给焦点环 + 唯一主操作
    val ACCENT    = 0xFFA7C5FF
    val DANGER    = 0xFFFF8A80

    // 字号：三级 + 一个微型
    const val HERO   = 40f   // 详情页片名 / 首页 hero 标题
    const val TITLE  = 20f   // 行标题 / 卡片标题
    const val BODY   = 15f   // 正文（简介、设置行）
    const val LABEL  = 13f   // 元信息、来源、"· 18 部"（大写 + letterSpacing 0.08）
    const val MICRO  = 10f   // 角标数字

    const val R_CARD = 6     // 卡片圆角（Aerial 比现在更方）
    const val R_GLASS = 14   // 玻璃容器
}
```

同时新增三个工厂，替换现有零散写法：

- `Theme.scrimTop(ctx, h)` / `Theme.scrimBottom(ctx, h)` —— 渐变幕布，替代所有"半透明黑色块"
- `Theme.glass(ctx, radius)` —— 白 6% + 1dp hairline 的背景
- `Theme.edgeFade(ctx)` —— 行左右各 80dp 的黑→透明渐变，切掉"半张海报"

## 3. 逐屏改法

### 3.1 首页（改动最大，观感提升 80%）

```
┌───────────────────────────────────────────────┐
│  DpadTV Pro            搜索 继续 直播 片源 设置 │ ← ghost 导航，未选中 62% 白
│                                                │
│   ┌──────── hero：当前高亮内容 backdrop ┐      │ ← 高度 38% 屏，cover 放大 + 40% 压暗
│   │  千与千寻 · 9.4 · 2001 · 日本         │      │   + 底部渐变并入背景，无硬边
│   └───────────────────────────────────────┘    │
│  电影 · 18 部                            更多 › │ ← LABEL 大写，字距 0.08
│  ▮▮▮ ▮▮▮ ▮▮▮ ▮▮▮ ▮▮▮ ▮▮▮ ▮▮▮ ▮▮▮ …        │ ← 卡片无边框，间距 20；左右 edgeFade
│  剧集 · 18 部                            更多 › │
│  ▮▮▮ ▮▮▮ ▮▮▮ ▮▮▮ …                           │
└───────────────────────────────────────────────┘
```

- hero 的图直接用当前行焦点的 `cover` 放大到 120% 模糊 0（不做 blur）+ 55% 压暗；焦点移动时 **220ms 交叉淡入**换图（唯一允许的长动效，因为它是氛围而非交互反馈）。
- 行标题去掉"电影 · 18 部"里的分隔点，改成右侧对齐的 `18 部`（LABEL + 62% 白），左标题 20sp。
- 卡片：聚焦 1.05 缩放 + `HAIRLINE` 描边 + 外发光（`shadowLayer` 用 ACCENT 8%），底部信息条淡入 120ms；不再用蓝色实心角标，状态角标改为"小圆点 + 文字"，来源角标只在聚焦时显示。
- 行右侧的"半张海报"用 `edgeFade` 吃掉，滚动到行尾时整行停在内边距上。

### 3.2 详情页

- 封面不再单独摆在左边，而是**整屏 backdrop**（同 hero 逻辑）+ 底部 60% 渐变；左侧留 132×196 封面做"锚点"，右侧文字浮在幕布上。
- 主按钮改成**白底黑字**（Aerial 里唯一的高对比按钮），次操作全部 ghost 描边。
- 选集格子：去掉面板底，改 hairline 描边 + 聚焦时白 10% 填充（现在 8 列有色块，视觉噪音偏大）。

### 3.3 直播

- 分组 chip → 玻璃胶囊：未选中透明 + hairline，选中白 10% + ACCENT 1dp。
- 频道列表行高 56 → 64，聚焦整行白 6% 填充 + 左侧 3dp ACCENT 竖条（比描边更"列表"）。

### 3.4 子页 / 设置

- `settingGroup` 的两列按钮 → 玻璃容器包一层，容器内按钮透明，聚焦只亮 hairline + 白 6%。
- 页标题从 DISPLAY(26) 换成 HERO(40) 会太大，统一用 TITLE(20) + LABEL 小字副标题（"共 3 个源"），形成"标题小、内容大"的 Aerial 比例。

### 3.5 播放器

- 控制条整条玻璃（白 6% + 上缘 hairline），进度条 3dp，已播放用白（不用强调色），缓冲 30% 白。
- 标题 TITLE(20) + LABEL(13) 元信息，幕布只保留顶部 140dp。
- 按钮全部去底色，只留 icon + 文字，聚焦时白 10% 胶囊。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| MiTV 中低端芯片跑不动实时模糊 | 全程不做 `RenderEffect`，用渐变 scrim + 半透明白；实测帧率写进 P2 验收 |
| hero 需要"当前焦点内容的图"，现在只有 cover | 用 cover 放大 + 压暗即可；后续可选接入 backdrop 字段，不阻塞 |
| 全黑底 + 62% 白字在 3 米外对比不足 | MUTED 提到 62%（现在是 #94A3B8 ≈ 灰蓝），LABEL 允许加粗到 Medium |
| 玻璃叠层在亮海报上"糊成一片" | 玻璃层最多两层；hero 幕布固定压 55% |
| 大改视觉会让已有截图/文档全部过期 | 文档按阶段追加，不做一次性大重写 |

## 6. 验收清单

- [ ] 任意一屏，字号不超过 4 种（40 / 20 / 15 / 13）
- [ ] 强调色只出现在焦点环与唯一主按钮，全屏不超过 3 处
- [ ] 焦点在任何位置都可见（暗海报 / 亮海报各验一次）
- [ ] 首页一屏可见 ≥2.5 行内容，且左右不再出现"半张海报"
- [ ] 电视实机 1080p 下逐屏截图，与模拟器一致
- [ ] 播放器控制条出现/消失无跳版（高度恒定）
