# UI / UX 审计（M4 附带）

审计范围：首页货架、浏览页、我的片单、搜索、结果页、播放入口、错误提示。
方法：模拟器逐屏截屏 + 对照 10-foot 规则（焦点可见性、6 米可读性、空/错/载三态、返回路径、动效时长）。

## P0（已修）

| # | 问题 | 影响 | 修法 |
|---|---|---|---|
| 1 | **首页一个导航入口都没有** | M1 把旧首页换成货架时，搜索/继续/直播/片源/设置全丢了；电视没有地址栏，用户被锁死在首页 | 顶部常驻导航胶囊（搜索·继续·直播·片源·设置），焦点可见 |
| 2 | 浏览页、片单页只能按 BACK 返回 | 遥控器上"看不到出口"= 不敢点 | 两页都加「‹ 返回首页」可聚焦按钮 |
| 3 | **触摸点一次没反应**，要再点一次 | `isFocusableInTouchMode=true` 的第一下只用来聚焦 | 全部改成 `false`：点一下即触发，遥控器焦点不受影响 |
| 4 | 启动弹「请求失败：网络失败：no such column: source」 | 数据库迁移漏列，还被错标成"网络失败" | `onCreate` 补列 + 版本升到 3 兜底迁移；错误归类待改 |

## P1（已修）

| # | 问题 | 修法 |
|---|---|---|
| 5 | 搜索页一进来就抢焦点到输入框，电视上立刻弹全屏键盘 | 焦点给列表，只有用户主动选输入框才起键盘 |
| 6 | 横屏输入时输入法进入「全屏提取模式」，整页被白底键盘盖住 | `IME_FLAG_NO_EXTRACT_UI` |
| 7 | 首页标语「豆瓣榜单 · 合并货架」是内部术语 | 改成「今晚看点什么」 |
| 8 | 侧车说"被限流"时客户端还回退直连，等于再补一刀 | 侧车报限流 → 本轮不走直连，只退避 |
| 9 | 片单只有 1–2 部时行尾一大片空 | 补「长按海报加入」占位 |

## P2（记录，未改）

- 模拟器顶部有 128px 黑边：这是 phone 版系统镜像的 StatusBar（真电视没有），不是应用问题；同时加了 `setDecorFitsSystemWindows(false)` 面向未来。
- 搜索页的加载指示仍是系统默认白色进度条，和深色主题不搭。
- 详情页、设置页仍是上游风格，与货架/片单的视觉语言不完全一致（改造半径大，留到打磨阶段）。
- 我的片单没有排序/筛选（300 条以内够用）。
- 1280 宽屏未验证（首页一行可能只放得下 4 张海报）。

# 第二轮：全局统一（设计令牌 + 跨页一致性）

## 做法

新增 `Theme.kt`：颜色 / 字号（DISPLAY 26 · BRAND 22 · TITLE 18 · BODY 15 · CAPTION 12.5 · MICRO 10.5）/ 间距 / 圆角 / 焦点环 / 胶囊 / 行标题 / 空态，全部集中一处。规则：**新代码不写魔法数字**。

三个自建屏幕（货架 / 浏览 / 片单）先接进去；`MainActivity` 的 `titleText` `hintText` `field` 等工厂也改为读令牌，视觉等价但源头统一。

## 这轮改了什么

| # | 问题 | 修法 |
|---|---|---|
| 1 | 状态角标和来源角标长得一样（都是实心蓝），"收藏"和"TOP250"混在一起 | 状态改**空心描边 + 状态色**（收藏蓝 / 在看绿 / 看过灰白 / 想看黄 / 弃剧红），来源保持实心蓝 |
| 2 | 我的片单 / 为你推荐 / 公共榜三行的上下间距不一致 | 统一 `GAP_XS / 14dp` 节奏 |
| 3 | 品牌名两套：首页 `DpadTV Pro`、设置 `DpadTV` | 统一 `DpadTV Pro`，`Pro` 用弱色；字号统一 22 |
| 4 | 设置页是一列高低不齐的按钮，右侧大片空 | 分「内容 / 播放 / 系统」三组，组内两列**等宽** |
| 5 | 直播页、继续观看页没有品牌栏 | 补品牌栏 + 统一页面边距（PAGE_X 48 / PAGE_Y 20） |
| 6 | 继续观看空态是左上角一行灰字 | 换成居中空态：标题 + 一句下一步 |
| 7 | 详情页 BACK 直接回首页，搜索上下文丢失 | 详情页加「‹ 返回」，从结果页进的回结果页 |
| 8 | 结果页 BACK 回首页，想改关键词得重来 | 结果页 BACK 回搜索页（保留关键词） |
| 9 | 结果为空时只有一个空网格 | 空态：「没找到「xxx」+ 换片名/检查片源」 |
| 10 | 搜索词没记住，空态无法引用 | 新增 `lastKeyword` |
| 11 | 详情页不能收进片单，手势不一致 | 长按片名 = 加入片单（与首页/结果页同一手势） |

## 仍未统一（下一步）

- 片源管理、播放设置、清理缓存等子页仍是上游的一列按钮布局（同一套 `settingGroup` 可以复用过去）。
- 直播页 504 个频道默认平铺，分组要手动切——建议默认进分组视图。
- 详情页、播放器还是上游排版，与货架的语言只做到"同色同字"，没做到"同节奏"。

# 第三轮：子页 / 直播 / 详情 / 播放器

| # | 问题 | 修法 |
|---|---|---|
| 1 | 片源管理、播放设置、首页排序：标题 18–20sp，比首页矮一档；列表行 17sp、内边距 18/12 各页不一 | 标题统一 DISPLAY；列表行统一 `Theme.LIST` + 16/15 内边距 + 极淡分隔线；**藏掉系统滚动条** |
| 2 | **直播 504 个频道平铺一列** | 默认落到「央视频道 → 卫视频道 → 最大分组」；分组 chip 条带计数；频道名按数字自然排序（CCTV3 在 CCTV12 前） |
| 3 | 详情页顶部没有品牌栏，与其它子页不一致；标题 24sp | 补品牌栏；标题 → DISPLAY；封面 132×196，把省下的高度给选集 |
| 4 | **详情页选集格子被挤出屏幕**（一整行来源 chip 吃掉了垂直空间） | 来源改成动作栏里的「换源 N」+ 弹窗；选集标题移到网格正上方；格子加面板底色 |
| 5 | 详情页没有"一键看" | 加「▶ 播放」主按钮，有进度时变「▶ 继续第 N 集」 |
| 6 | 结果页「‹ 返回搜索」和「重新搜索」干的是同一件事 | 删掉后者 |
| 7 | 结果卡片来源串太长，折行把三行信息挤成五行 | 只列前两个 + 「等 N 个来源」，单行截断 |
| 8 | 播放器动作按钮是蓝底反白，和全站"亮色描边"焦点语言不一致 | 改面板底 + 3dp 亮色描边 |
| 9 | 播放器标题 14sp、无幕布，亮画面上糊成一片 | 18sp + 顶部渐变幕布；时间标签改 CAPTION |
| 10 | 播放器进度条三层分不清（轨道 #4B5563 和缓冲色都偏亮） | 轨道压暗 #22304A、缓冲 #475569、已播放品牌色 |
| 11 | 播放器按钮「下集」排在最左，和时间轴方向相反 | 上集在前、下集在后 |
